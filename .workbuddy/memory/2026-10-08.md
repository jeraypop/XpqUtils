# 2026-10-08

## app/AndroidManifest.xml：ShizukuProvider 位置错误 → AAPT 报错（02:47）
- 报错：`app/build/intermediates/packaged_manifests/debug/processDebugManifestForPackage/AndroidManifest.xml:61:
  AAPT: error: unexpected element <provider> found in <manifest>.`
- 根因：宿主 `app/src/main/AndroidManifest.xml` 里
  `<provider android:name="rikka.shizuku.ShizukuProvider" .../>` 被写在了 **`</application>` 之后**，
  成了 `<manifest>` 的直接子元素。`<manifest>` 只接受 application / uses-permission / queries /
  uses-feature 这类元素，`<provider>` 必须在 `<application>` 内部 —— 报错行号指向合并产物，但源头在源码。
- 修复：把该 provider 整块移入 `<application>` 内（`ClearNotificationListenerServiceImp` 之后、
  `</application>` 之前），并删除 `</manifest>` 前的重复块。
- 关键事实：**accessibility 库的 manifest 里 ShizukuProvider 是注释掉的**（`accessibility/src/main/AndroidManifest.xml:55`），
  所以使用方必须自己在宿主 manifest 声明，别以为库会带。
- 验证：`./gradlew :app:processDebugManifestForPackage --offline --no-daemon` → **BUILD SUCCESSFUL**（15s）。
- 教训：往 manifest 里追加 `<provider>/<service>` 时，先确认落点在 `<application>` 标签**内**；
  AAPT 报的 `unexpected element X found in <manifest>` 一律先怀疑「标签跑到 application 外面了」。
