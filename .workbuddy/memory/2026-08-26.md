# 2026-08-26 工作日志

## NumberInputSDK：秒数=0 的边界决策
- 用户确认：输入秒数 0 时保持现状，**0 = 精确无容差**，`getRandomSeconds()` 恒定返回 0（不改代码）。
- 说明：池 = `0..0=[0]`，单元素池无法满足"每次不同"，数学上必然如此；语义上 0 即无抖动，合理。
- 对话框 `MIN_SECONDS=0`，0 仍是合法输入。

## NumberInputSDK：新增「随机延时生效」独立开关
- 常量：`KEY_RANDOM_ENABLED="random_delay_enabled"`、`DEFAULT_RANDOM_ENABLED=true`（默认开）。
- `isRandomEnabled()` / `setRandomEnabled(enabled)`：持久化开关。
- `getRandomSeconds()`：开头加 `if (!isRandomEnabled()) return getSavedSeconds()` —— 开关关时直接返回固定已保存秒数，随机延时不生效（不管输入几）。
- 秒数对话框 `showSecondsInputDialog()` 新增 `Switch@随机延时生效`（label + Switch），实时持久化到 `KEY_RANDOM_ENABLED`，切换即时生效。
- import 增加 `android.widget.CompoundButton` / `android.widget.Switch`。
- 验证：`:accessibility:assembleDebug --offline --no-daemon` → BUILD SUCCESSFUL。
- 备注：默认开启（true）；若希望默认关闭，把 `DEFAULT_RANDOM_ENABLED` 改为 false 即可。
