## 实机验证（TB320FC / 192.168.31.67）
- **两种形态都正常**：首次形态有「不同意｜同意」且无 ✕；关于形态无按钮、有 ✕、文案为中性版。
- 交互实测：✕ 点击关闭 ✅、点击弹框外部关闭 ✅、返回键**关不掉**首次弹框 ✅、
  「不同意」后 `ps -A | grep smdemo` 为 0（进程真的退出，回到桌面）✅、「同意」关闭弹框且进程存活 ✅。
- **踩坑：这台机器有「分身空间」(user 900)**，`adb shell am start -n <pkg>/<activity>` 会被
  `com.zui.resolver/ListUserActivity` 截走弹「请选择」，`--user 0` 也拦不住；而且 force-stop 后立刻 start
  会返回 "intent has been delivered to currently running top-most instance" 却什么都没起来。
  可靠做法：`sleep 1` 后重试 2~3 次 `am start --user 0 ...`（第一次往往失败，第二次就正常进界面）。
- **预览用的临时代码已全部删除**（`TempPrivacyPreviewActivity.kt` + 清单条目），确认 APK 清单里无残留、
  重新 installDebug 后设备上是干净包。
- 工作区里 `app/build.gradle`、`gradle/libs.versions.toml` 的改动**不是本次的**（用户自己在 IDE 里加的
  `apk1`/WXAPK 依赖 + core 1.17.0），我没有动它们。
