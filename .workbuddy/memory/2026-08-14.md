## 灵动岛自动初始化（受开关控制）
- 需求：应用/服务重启后自动初始化灵动岛，但受开关控制——开关关闭则不显示悬浮窗。
- `DynamicIslandFloatWindow.kt` 新增 `autoInit()`：主线程守卫；`if(!isEnabled()) return`（开关关闭则不显示）；否则 `show()`（内部幂等，仅启动监听、不立即弹窗，有日志才弹）。
- 挂钩点：`SelectToSpeakServiceAbstract.onServiceConnected()` 末尾（instance 已就绪、可用 TYPE_ACCESSIBILITY_OVERLAY）`runCatching { DynamicIslandFloatWindow.autoInit() }`；新增 import `ext.window.DynamicIslandFloatWindow`。
- 行为：开启过 → 重启后服务连接即自动监听；设置里关闭 → hide() 停监听，后续 autoInit 因 isEnabled()=false 不显示。与 showSettings 内开关逻辑一致。
- 验证：`:accessibility:assembleDebug --offline --no-daemon` → **BUILD SUCCESSFUL**。

## 修复：灵动岛「重启后打开设置拖动滑块看不到预览」
- 根因：`DynamicIslandFloatWindow` 是 `object` 单例，重启应用后内存 `enabled=false`、未 `startCollect`；但 `SharedPreferences` 里 `isEnabled=true`，设置对话框开关显示开启。`previewIsland()` 首行 `if(!enabled) return`，导致拖动滑块预览直接被拦截；只有手动关/开开关触发 `show()` 同步内存后才正常。
- 修复：`showSettings()` 初始化控件后，若 `enabledNow`（持久化开启）为真，立即 `show()`（同步 `enabled=true`+启动监听）并 `previewIsland()`，使打开对话框即同步状态并预览，拖动滑块也能实时预览。
- 验证：`:accessibility:assembleDebug --offline --no-daemon` → **BUILD SUCCESSFUL**。
